## 📌 Project Overview

MedTrack_DV is an interactive healthcare analytics dashboard developed using Tableau as part of the Infosys Springboard Data Visualization Virtual Internship.

The project aims to transform hospital operational data into meaningful visual insights that help hospital administrators, department heads, and management teams make informed decisions.

---

# 🎯 Objectives

- Monitor overall hospital performance
- Track patient admissions and discharge
- Analyze patient flow
- Evaluate department performance
- Monitor hospital resource utilization
- Build interactive dashboards using Tableau

# 📊 Dashboard Modules

## 🏥 Dashboard 1 – Hospital Overview

### KPIs

- Total Billing
- Total Patients
- Average Length of Stay
- Bed Occupancy Rate

### Visualizations

- Monthly Patient Admission Trend
- Patients by Department
- Patients by Hospital Region
- Admission Type Distribution
- Payment Status Overview

### Filters

- Department
- Hospital Region
- Payment Status
