# MedTrack_DV — Hospital Operations & Patient Analytics Dashboard

## About the project

MedTrack_DV is a healthcare analytics project developed to analyze hospital operations, patient admissions, department performance, and resource utilization.

The project uses Python for data cleaning and preparation and Tableau to create interactive dashboards.

## Dashboards

The project contains four Tableau dashboards:

1. **Hospital Overview**

   * Total admissions
   * Occupancy rate
   * Average length of stay
   * Readmission rate
   * Hospital performance

2. **Patient Flow**

   * Admission trends
   * Discharge analysis
   * Patient movement
   * Average stay
   * Patient load

3. **Department Analytics**

   * Department performance
   * Patient volume
   * Readmission analysis
   * Department efficiency
   * Treatment capacity

4. **Resource Utilization**

   * Bed utilization
   * Bed capacity
   * Staff allocation
   * Equipment utilization
   * Capacity planning

## Key KPIs
