# MedTrack DV – Dashboard Guide

## 1. Dashboard Overview

MedTrack DV contains four interactive Tableau dashboards designed to analyze different areas of hospital operations.

The four dashboards are:

1. Hospital Overview Dashboard
2. Patient Flow Dashboard
3. Department Analytics Dashboard
4. Resource Utilization Dashboard

The dashboards combine KPI cards, charts, filters, and interactive visualizations to convert hospital data into meaningful operational insights.

---

## 2. Hospital Overview Dashboard

### Purpose

The Hospital Overview Dashboard provides a high-level summary of overall hospital performance.

It helps users understand patient volume, billing, bed occupancy, length of stay, readmissions, and discharge activity.

- Bed Occupancy Rate: 80.83%

- Discharge Rate: 34.1%

### Visualizations

The dashboard provides analysis of:

- Monthly Admissions
- Revenue Trends
- Department Distribution
- Readmission
- Length of Stay
- Severity
- Billing
- Bed Occupancy
- Medical Conditions

### Filters and Interactivity

The dashboard uses interactive Tableau filters to allow users to explore the hospital data from different perspectives.

Users can filter the available dashboard dimensions and observe changes in the displayed visualizations.

### Business Purpose

The dashboard provides management with a quick overview of hospital performance and helps identify areas that require further analysis.

## 6. Dashboard Navigation

The four dashboards form a connected healthcare analytics suite.

The analysis flow is:

Hospital Overview
↓
Patient Flow
↓
Department Analytics
↓
Resource Utilization

This structure allows users to move from overall hospital performance to patient activity, department-level analysis, and resource utilization.

## 8. Dashboard Usage Workflow

A typical user workflow is:

1. Open the Hospital Overview Dashboard.
2. Review the main KPI cards.
3. Analyze hospital-level trends and distributions.
4. Navigate to the Patient Flow Dashboard.
5. Analyze admissions and patient movement.
6. Navigate to Department Analytics.
7. Compare department-level performance.
8. Navigate to Resource Utilization.
9. Review beds, staff, wards, rooms, and equipment.
10. Apply filters to investigate specific areas.
