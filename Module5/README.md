# Module 5 – Dashboard Building

## Overview

Module 5 focuses on building interactive dashboards for the **MedTrack_DV – Hospital Operations & Patient Analytics Dashboard**.

The cleaned and transformed hospital dataset from the previous modules is used to create meaningful visualizations and Key Performance Indicators (KPIs) that help understand hospital performance, patient flow, resource utilization, and operational efficiency.

## Objectives

- Build interactive hospital analytics dashboards.
- Display important hospital KPIs.
- Analyze patient admissions and hospital operations.
- Visualize department-wise performance.
- Analyze bed and resource utilization.
- Identify trends and patterns in hospital data.
- Create a clear and user-friendly dashboard layout.

## Key Performance Indicators (KPIs)

The dashboard includes the following major KPIs:

- **Total Admissions**
- **Total Patients**
- **Average Length of Stay (ALOS)**
- **Bed Occupancy Rate**
- **Bed Utilization Rate**
- **Readmission Rate**
- **Average Patient Wait Time**
- **Department Efficiency**

## Dashboard Sections

### 1. Hospital Overview

Provides an overall summary of hospital performance.

Key visualizations:
- Total admissions
- Bed occupancy
- Average length of stay
- Patient trends
- Admission trends
- Overall hospital performance

### 2. Patient Flow Analysis

Analyzes the movement and characteristics of patients within the hospital.

Visualizations include:
- Admissions over time
- Discharges over time
- Average length of stay
- Patient flow trends
- Admission and discharge comparison

### 3. Department Analytics

Provides department-wise analysis of hospital operations.

Visualizations include:
- Department-wise admissions
- Department-wise average length of stay
- Department efficiency
- Department workload
- Department performance comparison

### 4. Resource Utilization

Analyzes how effectively hospital resources are being utilized.

Visualizations include:
- Bed utilization
- Bed occupancy
- Resource availability
- Department-wise resource utilization
- Utilization trends
